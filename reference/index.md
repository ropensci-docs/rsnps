# Package index

  : Get all openSNP phenotypes, their variations, and how many users

- [`annotations()`](https://docs.ropensci.org/rsnps/reference/annotations.md)
  : Get all openSNP phenotypes, their variations, and how many users

  : Get openSNP genotype data for one or multiple users.

  : Internal function to get the frequency of the variants from

- [`get_gene_names()`](https://docs.ropensci.org/rsnps/reference/get_gene_names.md)

  : Get openSNP phenotype data for one or multiple users.
